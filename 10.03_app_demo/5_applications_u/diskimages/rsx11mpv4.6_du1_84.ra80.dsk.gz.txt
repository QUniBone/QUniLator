rsx11mpv4.6_du1_84.ra80.dsk.gz is NOT in this repository
========================================================

What it is
	The DECUS data disk of the RSX11M-PLUS v4.6 example, mounted on the
	second MSCP drive (uda1) by rsx11.mscp/rsx11mpv4.6_du_84.sh. The disk
	the example BOOTS from is rsx11mpv4.6_du0_84.ra80.dsk.gz, which is here.

Why it is missing
	300,681,182 bytes compressed, 1.72 GB expanded. GitHub refuses any push
	containing a file over 100 MB, so it cannot live in the repository, and
	it does not compress further: the image is genuinely full, only 2.8% of
	its blocks are zero. It is excluded in .gitignore by name.

What happens without it
	Nothing breaks. demo creates an empty image when the one a script names
	is not there, so uda1 comes up as a blank RA80 instead of carrying the
	DECUS data. The RSX11M-PLUS system on uda0 boots either way.

If you have a copy
	Put it in this directory under exactly that name and it is used again.
	To check it is the same disk:

		md5sum        rsx11mpv4.6_du1_84.ra80.dsk.gz
			5f7b9b633bda5a0403b4c4f6f63c4fa5
		zcat ... | md5sum   (the expanded image)
			c37c3c579d0b27fd4320d34ce417475d

	No download URL is recorded for this disk - it did not come with one,
	unlike the images covered by the *.url files in this directory.
